# Ereteti SACCO

A savings and credit cooperative (SACCO) management system.

## About

Ereteti SACCO is the home of the SACCO platform: member management, savings
and shares, loans, and reporting. This repository currently holds the starter
structure; application code will land in `src/` as it is built.

## Project structure

```
ereteti-sacco/
├── README.md          # You are here
├── LICENSE            # MIT
├── .gitignore
├── docs/              # Domain notes, decisions, guides
│   └── overview.md
├── src/               # Application source code
└── tests/             # Tests
```

## Getting started

1. Clone the repository.
2. Pick the stack and document the choice in `docs/`.
3. Place application code under `src/` and tests under `tests/`.
